# 河牌俱乐部

一个纯本地、单机的无限注德州扑克网页游戏。你对战三位电脑玩家；无需账号、网络服务或安装依赖。

## 开始游戏

直接在浏览器中打开 [`index.html`](./index.html) 即可。建议使用现代版本的 Chrome、Safari、Edge 或 Firefox。

每位玩家起始筹码 2,000，盲注固定为 10 / 20。可以弃牌、过牌或跟注、加注和全下。每手结束后点击“开始下一手”；牌桌上的“↻”可重置整场对局。

每手结束后也可以先点“查看所有人底牌”，亮出包括已弃牌玩家在内的所有底牌，并查看每个人这手的操作。再次点击可收起复盘。

快捷键：`F` 弃牌，`空格` 过牌或跟注。

## 规则检查

如果已安装 Node.js，可在此目录执行：

```sh
node --test game.test.js
```
